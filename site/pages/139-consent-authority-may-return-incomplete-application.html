§139 — Consent authority may return incomplete application

PagePA2026provision
Linked references reflect saved graph links. Unlinked references are candidate title matches and may need review. This prototype is not a verified legal publication.
  • (1) A consent authority may, within 10 working days after an application is lodged, determine that an application is incomplete if the application does not include the information required by section 132(2).
  • (2) If the consent authority decides that the application is incomplete, it must immediately return the application to the applicant with written reasons for the decision.
  • (3) A person may apply to the Planning Tribunal to review a decision that an appli- cation is incomplete.
  • (4) If an application that has been returned under this section is lodged again with the consent authority, that application must be treated as a new application.
