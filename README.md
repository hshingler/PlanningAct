# Planning Act Knowledge Base — next prototype update

This package builds a static website from the Logseq database EDN export. It preserves the graph as source data and generates HTML for GitHub Pages.

## What's improved in this version

- The homepage uses the existing Logseq page **Planning Act 2026 — Home** as its content.
- Every page has expandable **Linked references** generated from saved Logseq `:block/refs` relationships.
- Every page has expandable **Unlinked references**, generated by matching page titles in block text where no stored link to that page exists. These are discovery candidates and can include false positives.
- Reference entries link to the source page and, for block references, directly to the matching block anchor.
- Existing page and block UUID links, nested block structure, tags, search, and the four browse areas remain.
- The build manifest records page, block and reference counts.

## Source file expected

Keep your EDN export in the repository at:

```text
source/graph.edn
```

Do **not** put the EDN file inside `site/`. The `site/` directory is generated output and can be rebuilt at any time.

## Build locally

From the repository root:

```bash
python build_site.py source/graph.edn site
```

The script uses only the Python standard library. It reads the EDN file and replaces the generated `site/` directory; it does not modify the source export or SQLite database.

To preview locally:

```bash
python -m http.server 8000 --directory site
```

Then open `http://localhost:8000`.

## GitHub Pages

The included workflow `.github/workflows/deploy-pages.yml` builds from `source/graph.edn` and publishes `site/` using GitHub Actions. In the repository's Settings → Pages, set the build and deployment source to **GitHub Actions**.

If your repository still has an older workflow that runs `python build_site.py source/graph.sqlite site`, replace or delete that old workflow. Do not leave both workflows active.

## Important notes

- Linked references use the relationships stored in the Logseq export.
- Unlinked references are computed from page-title matches in block text. They are useful for discovery, not proof of a legal or conceptual relationship; check each result in context.
- Existing graph tags are retained, but the RSP/LUP/NEP and actor classifications are not yet comprehensively audited.
- This is a research prototype, not a validated legal publication. Verify statutory wording against official legislation.
