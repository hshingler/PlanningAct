# v3.1 — Visual styling update

This release applies the agreed archival-reference aesthetic to the v3 package without changing the site's information architecture or content.

## Changes
- Warm off-white page background and charcoal/ink text.
- Muted manila-yellow accents for reference-card headers, small filing tabs, and controls.
- A subtle archival card treatment around page titles, including a small “REFERENCE CARD” label, fine rules, and restrained shadow.
- Filing-tab-like treatment for existing breadcrumbs and tags.
- CSS-only details; no added images, fonts, JavaScript, or external dependencies.
- The updated stylesheet is included in `build_site.py` as well as the generated `site/assets/style.css` so future builds keep the theme.

## Preserved from v3
All source page content, navigation destinations, search index, graph links, grouped references, and block expand/collapse controls are preserved. This is a visual-only update.
